02

Inside the decision

Each candidate carries two independent scores: how confident the few-shot detector is that something is there, and how confident the verifier is that it is the right species. Plotting them against each other shows which stage is doing the work.

Stage 1 confidence vs verifier confidence

Connect an engine to populate.

Every dot is one candidate the detector proposed. Green = a real planted call, red = a false alarm. Separation along the vertical axis is the verifier doing useful work; separation along the horizontal is stage 1.

Stage 01

Learn the sound

Five calls become a compact fingerprint, from a network trained on 40 other Indian species — never the target.

Stage 02

Adapt to the recording

Wind, insects, distance and time of day change everything. The model briefly retunes itself to each recording before listening.

Stage 03

Verify

A large pretrained bird model re-checks every candidate, cutting false alarms from roughly six per ten true hits down to two.

04

Results

Ten held-out soundscapes, 120 planted calls, strict matching (IoU ≥ 0.3). Every scoring rule sees identical detections — only the ranking changes.

Recall vs call loudness

Detection degrades smoothly as planted calls approach the noise floor. The verifier does not collapse at low SNR, which we expected it might.

Detection quality vs species identity

Each point is a scoring rule. Up is better detection; right is better species discrimination. They do not move together.

On scope. These are event-detection scores on BirdCLEF soundscapes using this project's own matcher. They are not comparable to DCASE Task 5 leaderboard figures, which use a different dataset and the official evaluator. We report them as what they are.
05

The finding

A detector can score well on event detection while carrying almost no information about which species it heard.

Control

It was hearing birds, not the bird

We planted the target and four acoustically similar decoys into the same recordings at the same loudness. Stage 1's species discrimination came out at 0.459 — below chance. It scored the wrong species marginally higher than the right one.

Consequence

The standard metric picks the wrong model

Ranked by average precision, the winning configuration scores 0.500 on species identity — exactly chance. Optimising the number everyone reports would have selected the least species-specific model we built.

Stated honestly: one target species, and the seed-to-seed spread is not yet fully characterised. Testing whether this holds across more species is the next experiment, not a settled result.

Every mechanism tried, and its verdict. A clean record of honest negatives is what separates a research project from a demo — these are kept deliberately, not hidden.
